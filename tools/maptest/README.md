# AddVolcanicSoil 差分测试

验证 2026-08-10 那批地图脚本改动**没有夹带预期外的行为变化**。

## 跑起来

```bash
cd tools/maptest
lua run.lua                # 需要 Lua 解释器
```

推荐 **Lua 5.1.5**（SourceForge 上的 `luabinaries` 项目，文件名形如
`lua-5.1.5_Win64_bin.zip`，解压即用、无需安装）。选 5.1 是为了和游戏内嵌版本对齐；
这个测试本身在 5.1～5.5 和 LuaJIT 上都能跑。

没装 Lua 的话有个 Python 替代入口：

```bash
pip install lupa
python drive.py            # 等价，内嵌 Lua 5.5
```

退出码 0 = 通过，1 = 有回归。

## 核心思路：把改动拆成一条链，断言链的终点等于发布版

不去"逐格解释差异"——那需要我预先猜到所有间接后果，而实际上第一版测试就漏掉了
级联效应（保住的火山系奇观自己又会继续辐射火山土）。

改成把整批改动拆成五级，每级只做一件事：

| | 来源 | 这一级做了什么 |
|---|---|---|
| `v0_original.lua` | `373ddc4` | 最初实现：`math.random`、硬编码 feature id `35` |
| `v1_seeded.lua` | `30b3ebf` | 换成 `GetRandomNumber` + `g_FEATURE_VOLCANIC_SOIL` |
| `v1a_seam_fixed.lua` | 推导 | **只**修 X 循环越界（缺陷 ①） |
| `v1b_wonder_guarded.lua` | 推导 | **只**换自然奇观守卫（缺陷 ②） |
| `v2_rewritten.lua` | 当前 | 实际发布的重写版 |

两条断言：

- **v0 ≡ v1** —— 逐格、逐次 `SetFeatureType` 调用、抽取次数完全一致。
  证明那两步替换是纯重构。
- **v1b ≡ v2** —— 同样三项完全一致。
  证明发布版**恰好**等于 `v1 + 缺陷① + 缺陷②`，没有第三种行为变化。

用精确相等替代模糊归因，间接后果自动被涵盖：级联效应同时出现在 v1b 和 v2 里，
所以不影响等式成立。

`v1a` / `v1b` 由 v1 经最小编辑推导得来，编辑内容记录在提交信息里。

## 四种模式

| 模式 | 随机源 | 作用 |
|---|---|---|
| `place` | 恒"铺" | 消除随机，逐格对比 |
| `skip` | 恒"不铺" | 只留确定性的一环逻辑 |
| `stream` | 确定性 LCG | 真概率行为下的对比 |
| `nil` 越界 | — | 把 `Map.GetPlot` 越界改成返回 `nil` |

缺陷 ① 在 `place`/`skip` 下**不产生网格差异**（铺两次 = 铺一次），只产生
**扫描轨迹**差异。所以测试同时比对网格和轨迹，轨迹比对完全不涉及随机，
是对 ① 最直接的证明。

## 当前结果

```
-- 模式：总是铺 --   缺陷① 格差 0    缺陷② 格差 238
-- 模式：总是跳 --   缺陷① 格差 0    缺陷② 格差 137
-- 模式：真随机 --   缺陷① 格差 12   缺陷② 格差 420

v1 多扫的格子 737 个，其中不在 x==mWidth 列的：0
被 v1a 铺掉、被 v1b 保住的自然奇观格：72
由此级联产生的其它格差：166

Map.GetPlot 越界返回 nil：v1 报错（预期），v2 不报错（预期）
```

最后一项顺带回答了一个悬而未决的问题：旧代码**确实**访问了 `x == mWidth`。
它在游戏里没崩，所以 Civ6 的 `Map.GetPlot` 必然是东西环绕的。

## 变异测试

一个永远通过的测试没有价值。以下四种人为破坏都能被抓到：

| 变异 | 结果 |
|---|---|
| 二环概率 1/3 → 1/2 | 抓到（网格 + 调用序列） |
| 去掉自然奇观守卫 | 抓到（网格 + 序列 + 抽取次数） |
| X 上界改回越界 | 抓到（序列 + 抽取次数） |
| 去掉山地守卫 | 抓到（网格 + 序列 + 抽取次数） |

## 用例

5 个手工边界用例 + 40 张随机地图：

- 接缝火山（`x==0` 与 `x==w-1`）—— 命中 ①
- 普通火山旁的平地奇观 —— 命中 ②（普通火山那一支原先一个奇观都不排除）
- 奇观挨着奇观 —— 命中一环/二环名单不一致，也制造级联
- 极点与水山混杂
- 奇数宽度（检查 `x % w` 绕回）

地貌表里特意放了两个**不在旧硬编码名单里**的平地自然奇观（撒哈拉之眼、
伊克-基尔天然井），它们正是 ② 真正修掉的东西。

## 这个桩不是什么

它**不是** Civ6 地图生成器的模拟。`Fractal` 是 C++ 黑盒，无法复现。

- ✅ 能回答：这次改动有没有改变行为？改变的地方是不是只有预期的那些？
- ❌ 不能回答：这张地图好不好玩、像不像原来的手感

后者只能实机验证，但那时候 1～2 局冒烟测试就够（确认不报错、火山土正常生成），
不需要资深玩家开很多档。

## 已知简化

- 邻接用 odd-r 偏移坐标，东西环绕、南北截断。启动时自检对称性与绕回。
- `Map.GetAdjacentPlots` 返回稠密数组（跳过极点处不存在的邻居）。Civ6 实际会给出
  含 `nil` 的数组，而被测代码用 `ipairs` 遍历会在第一个 `nil` 处提前中断。
  对所有版本一致，不影响差分结论，但要测极点行为需要改这里。
- 只覆盖 `AddVolcanicSoil`。分形补陆（`GenerateFractalLayerWithoutHills`）需要
  额外桩掉 `Fractal.*` 和 `ShiftPlotTypes`，尚未做。

## 扩展

要测别的函数，照 `stub.lua` 里 `makeEnv` 的样子补上它用到的接口即可。
`Fractal` 那类黑盒塞任何确定性伪噪声都行——差分测试只要求两个版本吃到**同一份**输入。

下一个该测的是 `GenerateFractalLayerWithoutHills` 的去重（把 22 份合并成 1 份），
那正是最需要这套东西兜底的改动。
